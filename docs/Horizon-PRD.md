## 1. 市场背景与问题分析

### 1.1 现有财务管理软件的六大痛点

| # | 痛点 | 传统软件表现 | 用户真实需要 |
|---|------|------------|------------|
| 1 | **只管记录，不管规划** | 逐笔记账，然后给你看饼图和折线 | 想知道"钱该往哪放"，而不是"钱花哪了" |
| 2 | **预算太死板** | 设一个月度总额 → 超了就报警 → 焦虑 → 放弃 | 这个月在冲刺赛车就多拨点，下个月省钱徒步就少拨点 |
| 3 | **大目标太遥远** | 设一个"攒 30 万" → 一个进度条放三年不动 → 没劲了 | 把大目标拆成一个个能看见的小胜利，每完成一步都有回馈 |
| 4 | **吃喝拉撒跟梦想混在一起** | 吃饭和追梦在同一个列表里，花钱时根本没有边界感 | 追梦的钱单独放，雷打不动；日常的钱灵活处理 |
| 5 | **只跟钱打交道** | 钱花完就完了，跟你学会了什么、拥有了什么装备完全无关 | 花钱是实现目标的燃料，途中的技能、装备、经历都应该被记住 |
| 6 | **用起来太累** | 每杯咖啡、每顿午餐都要打开 App 手动记 | 一个月只打开一两次，平时瞟一眼就知道情况 |

### 1.2 市场空白

市面上的产品大致分三类，但没有一个能覆盖我们想做的事：

```
记账类 App（挖财、随手记、MoneyWiz）
  └── 擅长：把每一笔花销记得清清楚楚
  └── 缺失：不关心未来，只关心过去

预算类 App（YNAB、预算管家）
  └── 擅长：帮你控制这个月花多少
  └── 缺失：没法应对"这个月赛车、下个月徒步"这种灵活切换

目标存钱类 App（各种存钱罐应用）
  └── 擅长：帮你盯着一个目标慢慢攒
  └── 缺失：没法同时管"生活费+爱好+大梦想"好几层

手动表格（Notion、飞书、Excel）
  └── 擅长：自己想怎么搭就怎么搭
  └── 缺失：没有自动计算引擎，全靠手动维护
```

**Horizon 做的是**：把「自动分配资金」、「项目进度管理」和「让你愿意用下去的成就感」三件事合在一起，创造一种新的工具品类——**帮你管理整个人生目标的财务工具**。

## 3. 产品哲学与设计理念

### 3.1 三条核心原则

**这是 Horizon 的灵魂，所有功能决策必须遵守。**

| 原则 | 意思 | 怎么做 |
|------|------|--------|
| **不记流水账** | 用户不需要一笔一笔记花了什么 | 发工资那天自动把钱分好 + 日常开销自动预估，只管"还剩下多少" |
| **不制造焦虑** | 不给用户看复杂的分析图表和红色警告 | 只告诉你离梦想近了还是远了，用进度条和里程碑给正向回馈 |
| **不把吃喝拉撒和梦想分开** | 日常花销、月度爱好、多年大计，放同一个画面里 | 主界面就是你的目标全貌，所有操作围着它转 |

### 3.2 核心设计思路

| 思路 | 说明 |
|------|------|
| **帮你管未来，不是管过去** | 只在关键节点（发工资、月初决定、月底对账）跟你互动，平时不打扰 |
| **不同的钱放在不同的池子里** | 生活、应急、爱好、梦想——每个池子边界清晰，谁也别动谁的 |
| **让进度看得见摸得着** | 用点亮地图、填满蓝图、解锁成就徽章的方式，把抽象的数字变成具体的感受 |
| **自动跟着你的状态调整** | 这个月冲刺、下个月休整——App 跟着你的节奏调 |
| **不用精确，方向对就行** | 追求"大概对"，不追求"一分不差"。系统给你的数字是个参考，你觉得不准就随手调 |
| **用你听得懂的话** | 不说"收入"、"支出"、"转账"，说"工资到账"、"花了多少"、"挪一下" |
| **数据留在你手机上** | 不联网、不上传、不推销理财产品 |

### 3.3 用词对照

| 传统说法 | Horizon 的说法 |
|---------|-------------|
| 收入 | 到手的钱 |
| 支出 | 花掉的钱 |
| 预算 | 可用额度 |
| 储蓄 | 攒下的钱 |
| 账户 | 资金池 |
| 记账 | 备注（随便记，不用每笔记） |
| 超预算 | 花超了 |

## 4. 核心功能模块详解

### 模块 1：目标设定向导（首次使用）

**干什么的**：用户第一次打开 App，不是面对一张空白，而是跟着几步引导，把自己的人生目标录进去。

**用户心声**：我有梦想，我想在 5 分钟内把它变成一个可追踪的计划，而不是面对一张看不懂的空表格。

**具体操作**：

| 步骤 | 做什么 | 说明 |
|------|------|------|
| 1. 起名字 | 给你的目标起个名字 | "欧亚环线"、"去日本读研"、"提前退休"、"买第一套房" |
| 2. 选呈现方式 | 你想怎么看见进度 | ① **图片模式**：上传图片，攒够一张亮一张，或一张图切成格子慢慢亮。② **文字模式**：列出一个个节点，完成一个勾一个，配合进度条 |
| 3. 图片模式二选一 | 单图还是多图 | 见下方详解。文字模式跳过这步 |
| 4. 绑定资金池 | 自动创建一个"梦想基金"池子 | 设定每个月最少往里放的金额（雷打不动） |

**交互细节**：
- 一步一步走，每步一个画面，配上示例图
- 可以先粗略填一下，后面随时改
- 提供示例模板快速体验
- 设置完就能在预览里看到初始状态——全暗的图片或全空的清单

---

### 模块 2：资金池系统（核心引擎）

**干什么的**：工资一到账，自动按你设的规则分流到各个池子。池子叫什么、有几个、怎么分——全是活的。

**用户心声**：我希望工资自动分流，池子之间互不干扰。但不想用固定的名字——我想自己起名，自己决定有几个池子。

#### 本质：不是固定五个池子，而是几种「分配规则」

池子是你自己创建的。创建时决定两件事：
1. **叫什么、长什么样**——名字、图标、颜色，随你
2. **选哪种分配规则**——从下面几种里挑一个

| 规则 | 怎么分 | 适合 |
|------|--------|------|
| **固定金额** | 每次拿走确定的 X 元 | 房租、房贷、托儿费 |
| **按比例** | 拿走收入的 X% | 应急金（10%）、定投（15%） |
| **月费清单** | 列一笔笔固定开销，自动加总扣除 | 健身卡、视频会员、月票 |
| **剩余 × 系数** | 排在它前面的池子都分完后，剩下的钱 × 一个比例 | 爱好、娱乐这类弹性开销 |
| **兜底** | 前面全部分完，剩多少全归它 | 零花钱、自由支配 |

**规则通过优先级排序**——排前面的先分钱，排后面的吃剩饭。

#### 系统给的初始模板（名字全能改，不爱就删）

首次使用预建几个池子当起点，**名字只是建议，全部可改**：

```
模板 A："固定开销"  → 规则：固定金额 → 优先级 1
模板 B："应急金"    → 规则：按比例   → 优先级 2
模板 C："固定月费"  → 规则：月费清单 → 优先级 3
模板 D："梦想基金"  → 规则：固定金额 → 优先级 4 （绑定长期目标）
模板 E："爱好基金"  → 规则：剩余×系数 → 优先级 5 （内部分子项灵活分配，随时可调）
模板 F："零花钱"    → 规则：兜底     → 优先级最后
```

**你完全可以**：
- 删掉不需要的模板（没有固定月费就删掉模板 C）
- 新增自己的（比如加一个"养宠基金"，规则选固定金额）
- 调优先级（把梦想基金拖到应急金前面——先追梦，再应急，你说了算）
- 全部重命名，按你习惯来

#### 发薪日怎么跑（一个管道，依次流过）

```
工资到账 ¥12,000 →

  优先级 1 · 规则：固定金额
  "房租生活"：拿走 ¥2,180 → 剩余 ¥9,820

  优先级 2 · 规则：按比例 15%
  "应急金"：拿走 ¥1,800 → 剩余 ¥8,020

  优先级 3 · 规则：月费清单
  "固定月费"：拿走 ¥380 → 剩余 ¥7,640

  优先级 4 · 规则：固定金额
  "梦想基金"：拿走 ¥2,000 → 剩余 ¥5,640

  优先级 5 · 规则：剩余×60%
  "爱好基金"：拿走 ¥3,384 → 剩余 ¥2,256

  优先级最后 · 规则：兜底
  "零花钱"：拿走 ¥2,256 → 剩余 ¥0
```

**交互细节**：

- 发工资当天推送："这个月的钱已按你的规则分好。"
- 每个池子一张卡片，显示余额 + 进度条
- 点进去看详情：剩多少、花多少、预估还能撑几天
- 拖拽池子卡片 = 调优先级，分配顺序跟着变

### 模块 3：池子详情与子项管理（替代传统"月度预算"）

**干什么的**：点进任意一个资金池，管理这个池子里面的钱具体怎么花。给每件事设预算、选追踪方式、随时调整。不再需要一个单独的"月度计划"弹窗——池子本身就是你的仪表盘。

**用户心声**：我的爱好基金里有赛车、徒步、射箭三件事。这个月我想赛车多跑几次、徒步照常、射箭暂停——直接在池子里调一下就好，不用填一个"你这个月是什么模式"的表单。

#### 池子内部结构

每个池子可以包含若干**子项**——这笔钱具体用在哪些事上：

```
爱好基金池（本月入账 ¥3,384）
  ├── 🏎️ 赛车    ¥1,880  [按次 · 4次 × ¥470]   🛞🛞🛞⬜  剩1次
  ├── 🥾 徒步      ¥800  [按月估算]             ████░░  52%
  ├── 🏹 射箭      ¥500  [固定月费]             ██████  OK
  └── 💤 暂存      ¥204  → 未花完月底默认转入 [梦想基金 ▼]
```

#### 子项的三种追踪方式

| 方式 | 怎么用 | 适合 |
|------|--------|------|
| **按次** | 设单次价格 + 预估次数，每次消费后点一下"又做了一次"，自动倒计数 | 赛车、攀岩、私教课、旅拍项目 |
| **按月估算** | 设月度总预算，系统每天自动扣估算值，懒得细分时用 | 徒步（装备+路费混在一起）、日常吃喝 |
| **固定月费** | 写死每月多少，自动扣，不追踪次数 | 健身卡、视频会员、射箭馆月卡 |

#### 随时调整，不用等到下个月

跟传统预算最大的不同：**不需要月初选模式**。你想调，随时进池子：

- 赛车临时想多跑一次 → 从徒步或暂存里拖点钱过来
- 这个月射箭馆装修不开门 → 把射箭子项暂停，预算自动划入暂存
- 月底发现徒步花了不到一半 → 暂存自动累积，按你预设的规则转入梦想或装备基金

#### "暂存"的设计

每个池子自动带一个**暂存**子项——子项分配完后的缓冲区：

- 子项没花完的钱自动归入暂存
- 池子设置里指定"暂存的钱月底默认转入哪个池子"（默认：梦想基金）
- 你也可以随时手动把暂存的钱挪到某个子项（"这周末想多跑一节赛车"）
- 暂存余额在桌面上不显示，不制造"还有钱没花"的焦虑

#### 替代的正是传统"月度预算"的心智负担

让用户不再需要：
- ❌ 面对一个"选模式"的表单（赛车冲刺？徒步省钱？——为什么要只选一个？）
- ❌ 月初做一次决定然后被锁死一个月
- ❌ 被模式名称暗示"这个月你只能专注一件事"
- ✅ 而是：打开池子，看到所有子项，想调就调——跟真实生活一样自然

#### 别的场景也能用

- 摄影师：器材基金下面分"新镜头"、"无人机"、"灯光设备"，各自设预算，看哪个先攒够
- 学生：学习基金下面分"JLPT 报名"、"托福报名"、"语言培训班"，每个都有截止日期和金额
- 创业者：项目基金下面分"原型开发"、"差旅路演"、"外包设计"，接单月多分点，创作月少分点

### 模块 4：目标进度可视化（让你看见自己走了多远）

**干什么的**：把你攒的钱映射到一张（或多张）图片上，钱攒得越多，图片越亮。这是 Horizon 跟所有其他软件最不一样的地方。

**用户心声**：我不想对着一个枯燥的百分比——我想看见自己真的"走在通往目标的路上"。

**核心设计**：图片模式分两种——**单图**和**多图**。再加一个纯**文字模式**。总共三种，覆盖一切。

1. 上传 N 张图片（比如 10 张——深圳、喀什、阿拉木图、莫斯科……各一张）
2. 设定总预算（比如 30 万）
3. 系统自动算：每张图预算 = 总预算 ÷ 图片张数（30 万 ÷ 10 = 3 万/张）
4. 每张图也可以手动调预算，最后自动汇总

### 模块 6：自动预估 + 手动校准（省掉每天记账的麻烦）

**干什么的**：对于吃饭通勤这种弹性开销，系统每天按你的预算自动扣一个估算值。你觉得不准？随手拖一下滑块就行。

**用户心声**：我完全不想记每天吃饭花了多少钱。但我希望有一个大概的"电量条"让我隐约感觉到这个月生活费还剩多少——最好这个电量条每天自己会掉。

#### 6.1 自动预估

```
你设定：生活必需池月度总额 1,800 元

系统算出：1,800 / 30 = 大约 60 元/天

每天凌晨自动更新：
  ┌──────────────────────────────┐
  │  生活费    ████████░░  72%   │
  │                              │
  │  已过掉了约 504 元              │
  │  还剩约 1,296 元 / 21 天       │
  │  日均约 62 元/天               │
  └──────────────────────────────┘
  
  你的感受：
  - 每天醒来，电量条自己掉了一小格
  - 什么都不用做，但隐约有体感
  - "今天中午好像吃贵了"这个念头会自动冒出来
```

**估算方式**：
- **平均模式**（默认）：总预算 ÷ 总天数
- **周末多花模式**（可选）：周末权重 ×1.5
- **按周期调整模式**（可选）：跟着你发工资的节奏走

#### 6.2 手动校准

当你觉得"系统估的"跟"自己感觉的"对不上时，拖一下就好：

```
你看到生活费还剩 56%，但感觉只剩 40%
  →
  手指按住滑块从 56% 拖到 40%
  →
  系统算出差额：16% × 1800 = 288 元
  →
  弹出两个按钮：
    这 288 元主要是花在了？
    [🍽️ 聚餐]  [🛒 购物]  [算了不填]
  →
  搞定，电量条变黄提醒一下
  系统回你一句："已调整，还在可控范围"
```

**这背后的巧思**：
- 系统根据你过去几个月的实际花销规律，给出一个合理的估算值，并明确标注"此为估算"
- 你看了觉得跟体感差不多，就放心了——不用每天记账也有方向感
- 觉得跟体感对不上？随手拖一下滑块校准，系统记录修正并改进后续估算
- 把"被迫记账"变成了"瞄一眼，不对就调"——满足的是掌控的冲动，不是完成任务的负担
- 忘记调一周？甚至一个月？完全没关系——回来后看一眼银行余额，一次性拖到正确位置就好

#### 6.3 异常提醒（可选功能）

```
你平时周三晚上自己做饭，今天却跑到了一个高级商圈待了很久

系统察觉（通过位置 + 时间规律，完全在你手机上算，不上传）：
  "今天的花费比平时多？需要调一下生活费余额吗？"
  [调一下]  [没事，正常]

（系统不需要知道你具体花了多少，只需要感觉模式不对）
```

**注意**：位置提醒默认关闭，需要你主动去设置里打开。所有位置数据只留在你手机里。

### 模块 7：我的装备（一切需要花钱获得的东西）

**干什么的**：所有需要花钱才能获得的东西——实体装备、课程、考试、执照——统一在这里管。加进来、绑定扣款池、后台攒、够了亮、下单收割。

**用户心声**：我想知道我已经有什么装备、它们的状况怎么样、下一个该买什么——而不是每次看到购物链接就冲动下单。

#### 7.1 我的装备

**核心交互**：把想买的装备加进来，绑定一个资金池，后台自动攒。当池子里的钱够买其中几件时，它们全部亮起——但钱只够买一件。**你选一个下单，其他的立刻变暗。** 这种"看到所有选项、然后亲手放弃其他"的瞬间，就是帮你理性消费的核心体验。

#### 装备池机制

```
你添加"想要"装备时，自动进入装备池，绑定一个资金池（默认选一个，
也可以手动指定从哪个池子扣）。

装备池 = 你所有"想要"装备的集合 + 绑定的资金池余额

系统不会替你做决定，它只做一件事：
→ 当池子余额 ≥ 某件装备价格时，那件装备亮起（全彩）
→ 亮起的装备都是"你现在买得起"的
→ 但你只能选一个
```

#### 完整场景：三件装备，五千块钱，只能拿一件

林远有三件想要的装备，全部扔进了装备池，绑定资金池"装备基金"：

| 装备 | 价格 | 
|------|------|
| 拉力头盔 | ¥2,800 |
| 徒步背包 | ¥1,800 |
| 无人机 | ¥4,200 |

装备基金当前余额：**¥5,000**。

**此刻，三件全部亮起——因为钱够买任何一件。**

```

│  ┌────────┐  ┌────────┐  ┌────────┐     │
│  │   🪖    │  │   🎒    │  │   🛸    │     │

```

**发生了什么**：
- 拉力头盔扣了 ¥2,800 → 状态变"已买"，保持全彩（这是战利品）
- 余额剩 ¥2,200 → 无人机 ¥4,200 买不起了 → **立刻变暗**
- 徒步背包 ¥1,800 还买得起 → 保持全彩，在问你"要不要顺便？"
- 这一刻林远清楚感受到：**选头盔，等于暂时放弃无人机。** 这不是 App 在说教，是他亲眼看见的。

**他也可以选"不再等等"**——攒到余额 ¥4,200 以上时，无人机自动重新亮起。

#### 这个交互在解决什么

传统购物是你看到价格 → 大脑抽象判断"买不买得起" → 冲动下单 → 后悔。

Horizon 装备池的做法：
1. 先让你看到"你能买起好几件"——制造丰裕感
2. 让你亲手点下去——制造掌控感
3. 下单瞬间，没选的变暗——**制造失去感**
4. 失去感 > 获得感的心理冲击，让你自然停下来想"我真的要这个吗"

**不用锁、不用限额、不用警告——只用一张图变暗，就让用户自己管住了自己。**

#### 怎么绑定资金池

添加装备时，选择扣款来源：

```
添加装备 →
  名称：拉力头盔
  价格：¥2,800
  从哪个池子扣？
    ○ 装备基金（¥500/月，余额 ¥5,000）
    ○ 爱好基金（本月余额 ¥3,384）
    ○ 自由支配（余额 ¥2,256）
    ○ 新建一个专用池子
```

不同池子意味着不同的取舍——从"爱好基金"扣意味着这个月少跑两节赛车，从"自由支配"扣意味着零花钱少了。选哪个池子，本身就是一次权衡。

---

**功能清单**：
- 添加装备：名称、分类、价格、状态（想要/已有/该保养了）、绑定扣款池
- 装备池视图：所有"想要"装备按图片卡片展示，余额够的自动亮起
- 下单交互：选一件 → 其他余额不够的立刻变暗 → 确认后扣款 → 记入成长记录
- 生命周期追踪：已有装备记录用了多久，该保养时提醒
- 关联梦想目标：环线需要的装备逐件解锁，每件都推了梦想进度

**只要需要花钱才能获得的东西，都可以当装备管。包括课程、考试、执照。**

### 模块 8：成长记录（你的个人传记）

**干什么的**：自动把时间线上值得记住的事件串起来，生成一条可视化的人生记录。

**用户心声**：多年后回看，我希望有一份记录——不是我花了多少钱，而是我为梦想做过什么事。

**自动记录的事件**：

### 模块 10：手机桌面组件（不用打开 App 就能看）

**干什么的**：放在手机桌面的小组件，瞟一眼就知道大概情况。

**三种小组件**：

| 组件 | 显示什么 | 什么时候更新 |
|------|---------|---------|
| 🌅 **梦想进度** | 缩略版路线图，走完的路段高亮 | 存款余额变化时 |
| 🔋 **生活费电量** | 环形进度条 + 还剩几天 | 每天凌晨自动更新 |
| ⏱️ **爱好倒计时** | 显示当前活跃子项的追踪状态：赛车按次还剩几次 / 徒步按月还剩多少 | 每次手动打卡后 |

**设计原则**：
- 不显示精确数字，只看个大概感觉即可
- 每天解锁手机时不小心看到"又往前推了一点"
- 不发催命通知，只发里程碑达成的好消息

## 附录 B：关键设计决策

| 抉择 | 选项 A | 选项 B | 选了 | 为什么 |
|------|--------|--------|------|------|
| 要不要保留逐笔记账 | 保留简化版 | 完全去掉 | **完全去掉** | 只要有记账入口，用户就觉得"得记"，违背初衷 |

| 第一次打开看到什么 | 空白 + 教程 | 引导你设定目标 | **引导设定目标** | 用户是带着梦想来的，应该马上定义梦想 |
